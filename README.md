## 一、这个目录是什么

本目录是《基于大模型的骑行功率训练系统的设计与实现》毕业设计项目中，**骑行可视化分析**与**大模型接入**两部分工作的落地目录。后续与本主题相关的新代码、脚本、图表与阶段产出物统一放在这里，不再散落在 `Desktop\毕业设计` 根目录。

项目级的总体设计、决策与排期不写在本目录，仍以根目录的 [PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) 为唯一事实来源。本目录只记录本主题的工作内容与进展。

## 二、工作范围

| 板块 | 内容 | 对应项目决策 |
|---|---|---|
| 骑行数据可视化分析 | 功率曲线、区间分布、十四天负荷趋势、活动对比等图表与交互 | D12 亮点①；前端技术栈见 D7 |
| 大模型接入 | 训练计划生成、计划审核、基于主观反馈的自适应调整 | D5、D12 亮点②③ |

技术约定沿用项目既有决策：前端 Vue 3 + Element Plus + ECharts，前后端分离；指标计算走本地规则引擎，训练计划生成走云端 LLM API，审核为规则校验加 LLM 复核。

## 三、目录内约定

1. 数据、密钥等不进入本目录跟踪范围；大模型 API Key 必须外置为环境变量，不写入源码或配置文件。
2. 一次性验证脚本与中间产物放本目录下的 `tmp/`，验证完即弃。
3. 涉及项目级决策的改动（表结构、目录结构、层间依赖等），先改 `PROJECT_CONTEXT.md`，再改这里的代码。
